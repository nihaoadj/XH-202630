# 2026-10-26 项目更新说明

本次汇总 `feature/architecture` 分支相对 `0261049` 的当前项目更新，包含之前积累的工程、后端和前端改动，以及本次完成的 E1。通过 Pull Request 集成到 `dev`。

## 已实现的变化

### 文本生成 Worker 与恢复

- SQLite 文本任务通过持久化调度领取，普通生成、续作和反馈后续任务统一接入；增加独立 `backend/scripts/generation_worker.py`、健康检查、进程锁、续租和有序停机，本地启动脚本同步管理该进程。
- 生成入口支持 `Idempotency-Key`，执行以 owner／epoch／租约隔离；事务提交核对执行权，线程继承执行上下文，重试创建关联原任务的新 Run，启动及周期对账处理遗留任务和反馈／课程状态。
- SQLite 迁移 `p0_34` 为任务增加调度快照、领取／租约、幂等及重试字段和索引；旧任务维持 `legacy`，不自动移交新 Worker。

### 报告读模型与一致性快照

- 增加有界快照缓存、并发构建协调和时间窗口失效。GET／304／SSE 复用一致的 revision／元数据，资源信誉使用批量读取与 keyset 分页，正式测评聚合覆盖完整历史，移除原10,000条截断。
- SQLite 迁移 `p0_35` 增加事务触发器、安装标识／epoch水位和读索引；优化路径核对仓储组合及协议，不满足条件时使用兼容读取路径。迁移提供回滚入口，保留业务事实；合成基准方法见 [报告读取基准](testing/report-read-performance.md)。

### 前端生成命令与课件事件同步

- 重试、追加资源、单资源重试等命令拆为请求计划和协调逻辑，绑定 learner／run／命令版本及 busy owner；切换任务、离开页面和迟到响应不再覆盖当前页面状态，已受理任务继续在服务端执行。
- 课件事件改为 IndexedDB 持久队列与独立发送器，按账号、资源及发布版本隔离，增加 ACK、批量发送、有界重试、跨标签协调、登录失效暂停和失效版本隔离；界面提供保存／同步状态与未同步记录导出。

### 分层、契约与工程检查

- 前端 API 归各业务域，旧集中入口保留兼容导出；新增生成的 DTO／常量、JSDoc／port 类型及关键响应校验，`.gitattributes` 固定生成契约的 LF 字节，防止跨平台漂移。
- 反馈分析、简答评分 Prompt／模型调用归学习 Agent；反馈证据、后续计划和能力投影按职责拆分。课件教学准备、场景校验和候选处理归独立阶段，查询经 Service 门面，发布安全硬门继续生效。
- 增加 AST 架构边界、契约生成漂移及相关正负例检查，扩展 CI 和统一测试入口。四份旧工程记录被整理替换，当前入口为 [结构优化记录](architecture-optimization-2026-10-25.md)、[优化方向](project-optimization-directions-2026-10-22.md) 和 [测试说明](testing/README.md)。

### E1 资源证据分配

- 五类普通文本资源复用公共查询并补充类型查询，保留多节点／多类型命中归属；统一候选池固定 owner 及其评分／排名，最终公共 C／专属 S／冻结 E 通过版本化契约和指纹追踪。
- Planner 在增强模式一次读取完整最终 E，并预检完整消息／schema和输出预留；各资源生成、来源展示、普通审核、结构化payload、Claim抽取／Judge和修订统一使用原 spec 的 A。原工作流节点／顺序和全局回退条件保留。
- 增强默认关闭。真实模型质量、完成率、时延和净成本尚未对照验收；本说明仅记录已实施功能。

## 升级与运行影响

- SQLite 配置要求 `GENERATION_DISPATCH_MODE=worker`，需与 Web 和课件 Worker 一起启动独立文本 Worker，默认健康端口8082；`background` 保留给适用的非SQLite场景。
- 数据库启动流程接入 `p0_34`／`p0_35`；维护前备份，迁移及回滚边界按 [部署说明](deployment.md) 执行。
- `RESOURCE_AWARE_RETRIEVAL_ENABLED=false` 默认保持；独立查询上限默认10。启用 AI 规划前需明确设置部署模型真实窗口 `RESOURCE_AWARE_PLANNER_CONTEXT_TOKENS`，输入预算默认32768；超限严格失败或按既有政策显式降级，不静默裁剪证据。策略在实际建立Run时冻结，排队job按执行时配置选择。
