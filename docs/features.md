# 功能说明

系统按学习方向组织知识库、技能节点和先修关系。学习者在一个方向下建立画像，从能力起点出发，取用材料、提交测评，再根据反馈确认下一步。

[新建方向](#1-建立学习方向) · [资源生成](#2-生成与审核资源) · [资料学习](#3-阅读实操与导学) · [测评反馈](#4-测评与下一轮) · [历史与报告](#5-历史与学情报告)

## 1. 建立学习方向

从工作台进入「新建学习方向」。开户后可在「用户资料」维护身份、学历、岗位和经验。每个方向单独保存问卷、诊断、资源和学习进度，可在工作台切换画像。

| 步骤 | 操作与结果 |
|---|---|
| 选择领域与方向 | 在目录中选择环境已开放的方向，例如 RAG 工程链路培训。系统使用该方向的知识库、节点图谱和题库。 |
| 填写方向问卷 | 提供学习目标、学习方式、难度偏好和每周时间，建立初始学习画像。 |
| 完成能力诊断 | 根据当前方向的诊断题判断能力起点。诊断结果用于定阶、首批节点推荐和可选范围。 |
| 确认首批资源 | 在候选中确认一个主节点，选择需要的资源，可补充学习要求，并为支持的资源开启事实核验。 |

阶段测评、纠错与下一轮选择按学习轮次组织。新建轮次需启用服务端创建能力。[部署配置](deployment.md#2-配置和初始化)

## 2. 生成与审核资源

提交后进入「资源生成」。通过画像、批次和资源选择器定位任务，查看诊断、检索、规划、生成和审核轨迹。展开步骤可核对检索摘录、产物版本和审核结论。使用「追加资源」为当前主节点补充所需材料。

| 资源 | 适用场景 |
|---|---|
| 讲义 | 理解概念、术语、应用条件和常见误区 |
| 实操指南 | 按准备、实操、验证和复盘完成操作，查看步骤中提供的输入与代码 |
| 分阶测试题 | 自查理解与应用能力，在阶段测评中提交正式结果 |
| 复习清单 | 主动回忆、辨析概念、对照答案与知识小结 |
| 案例分析 | 结合具体情境理解问题、方案选择及其取舍 |
| 个性化纠错训练包 | 在测评反馈后围绕指定节点复习易错知识，并完成有提示的练习和迁移练习 |

**普通审核**检查知识覆盖、内容、自包含性和难度等要求。**Claim 核验**是供支持的资源选择的事实核验环节，逐条展示陈述、判定与可见证据。启用补检后，符合条件的缺证陈述可补查同一知识库并重判。新建实操指南执行普通审核。

只在报告明确提示「待用户决定」且当前版本符合发布条件时，可从审核报告确认发布。失败或未发布资源满足恢复条件时可单独重试，重试保留已发布版本。[审核与发布机制](architecture.md#文本生成与发布)

## 3. 阅读、实操与导学

- **资源架与专注阅读**。在「学习资源」中按方向和批次切换已发布材料，阅读或下载正文，展开引用核对出处。从生成页也可用「学习模式」直达当前材料。
- **Tutor 问答**。阅读时通过 Tutor 追问某个概念或选中的片段。Tutor 使用当前资源及允许的证据提供分级帮助，受限测评答案和评分信息受保护。
- **互动课件**。在生成页通过「追加资源」选择 HTML 互动课件，对符合条件的已发布实操指南或复习清单创建任务。多选时每份来源独立生成。审核发布后，可从资源架预览、下载，并保存当前课件版本的学习进度。

## 4. 测评与下一轮

在资源架选中分阶测试题后进入「反馈测评」，系统定位对应轮次和阶段。阶段内题组按主节点和复习节点组织，统一提交并分别判分。结果页可回看评分、题目反馈和学习小结，学习者也可填写学习反思。

| 后续操作 | 适用情况 | 结果 |
|---|---|---|
| 再次测评 | 用同一题组比较自己的表现 | 创建独立测评会话与成绩，沿用本阶段冻结题组 |
| 纠错巩固 | 针对本轮已测节点的薄弱项加强练习 | 在本轮增加纠错阶段，为所选节点生成纠错包和新分阶测试题 |
| 下一轮学习 | 补齐先修节点、继续巩固或推进到后继节点 | 确认一个主节点及所需资源，符合条件时附带一个已学复习节点 |

系统根据节点评分和先修条件给出候选。存在前置缺口时可优先补学，满足条件后可建议返回原节点。生成后续材料需要学习者确认，刷新后可以恢复已确认的选择。

## 5. 历史与学情报告

- **学习历史**记录当前方向经历的轮次、阶段、生成任务与正式测评。展开对应记录可查看已关联资源和执行详情。
- **学情报告**支持近 7、30、90 天窗口，展示客观正确率、节点掌握度、能力雷达、资源难度与学习路径。可按批次查看生成资源质量，并浏览下一轮学习重点。
- **质量来源**随指标展示。知识覆盖来自普通审核，Claim 幻觉率基于已核验事实子集，普通审核参考线单独显示。未测量的项目标为待测或未知。[正式评测口径](testing/competition.md)
