# 功能文档

> 项目编号：XH-202630  
> 项目名称：领域知识个性化生成与多智能体协同决策系统  
> 文档版本：v1.0  
> 文档定位：描述系统功能范围、核心流程、页面能力和指标要求。

## 1. 项目定位

系统面向多领域技能学习者，根据学习者画像、学习主题和当前接入的知识库，生成个性化学习资源，并通过多 Agent 协同、审核纠偏、学习反馈和学情报告形成闭环。

系统不绑定任何特定领域。接入不同知识库后，可用于不同方向的工程技能培训或领域知识学习。

## 2. 核心闭环

```text
学习者画像输入
→ 能力诊断
→ 知识库检索
→ 学习路径规划
→ 个性化学习资源生成
→ 审核纠偏与知识溯源
→ 学情报告与可视化
→ 学习反馈
→ 反馈决策
→ 动态调整学习路径
```

## 3. P0 功能清单

| 编号 | 功能模块 | 功能说明 | 主要输出 |
|------|----------|----------|----------|
| F01 | 学习者画像管理 | 保存背景、能力得分、强弱项、学习目标 | 学习者画像 |
| F02 | 能力诊断 | 根据画像和主题识别能力等级、知识盲区 | 能力等级、薄弱点 |
| F03 | 知识库检索 | 从当前领域知识库召回证据片段 | 来源片段、相似度 |
| F04 | 学习路径规划 | 决定先学、补什么、跳过什么、挑战什么 | 学习路径、资源要求 |
| F05 | 个性化资源生成 | 生成资源，并按审核指令对命中类型定向产生不可变新版本 | 学习资源、引用来源、版本链 |
| F06 | 审核纠偏 | 检查事实、证据、难度和覆盖率，输出通过/返工/拒绝/人工审核 | 结构化问题、返工指令、发布结论 |
| F07 | 学习反馈与反馈决策 | 根据答题或实操表现判断下一步策略并更新画像 | 反馈决策、更新画像、下一轮建议 |
| F08 | 学情报告 | 聚合画像、资源、反馈形成报告 | 雷达图、路径、历史摘要 |

## 4. 多智能体协同

| Agent | 功能定位 | 输入 | 输出 |
|-------|----------|------|------|
| 学情诊断 Agent | 分析画像和学习主题 | 学习者画像、主题 | 薄弱知识点、能力等级 |
| 知识库检索 Agent | 检索相关知识片段 | 主题、薄弱点 | 带来源的知识片段 |
| 学习路径规划 Agent | 规划学习顺序和资源要求 | 能力状态、证据 | 学习路径、资源生成要求 |
| 个性化资源生成 Agent | 首次生成或只修改返工指令命中的资源 | 画像、路径、证据、上一版本、结构化返工指令 | 讲义、实操指南、测试题新版本 |
| 审核纠偏 Agent | 审核事实、证据、难度和覆盖率 | 当前资源、知识库证据 | approve/revise/reject/human_review、结构化问题与指令 |
| 反馈决策 Agent | 根据学习反馈调整后续策略 | 画像、资源反馈、答题明细、历史反馈 | 决策理由、知识状态更新、下一轮建议 |
| 协同决策节点 | 决定通过或重生成 | 审核结果、迭代次数 | 最终决策 |

## 5. 资源类型

| 资源类型 | 内容要求 |
|----------|----------|
| 定制讲义 | 概念解释、关键知识点、示例说明、来源引用 |
| 实操指南 | 操作步骤、注意事项、常见错误、验证方法 |
| 分阶测试题 | 基础题、进阶题、答案或解析，作为反馈数据来源 |

生成结果需要包含 `resource_id`、`resource_type`、`difficulty`、`content_text` 或 `file_path`、`knowledge_points`、`source_refs`、`version`、`parent_resource_id`、`review_status` 和 `publication_status`。只有最终审核通过的当前版本进入资源库和下载接口；草稿、旧版本、返工、拒绝和人工审核版本保留在 Run 时间线中。

## 6. 页面能力

| 页面 | 建议路由 | 功能说明 |
|------|----------|----------|
| 首页 | `/` | 系统入口和 Demo 入口 |
| 学习者画像页 | `/learner` | 录入和查看学习者画像 |
| 个性化资源页 | `/generate` | 触发生成、展示资源和 Agent 轨迹 |
| 资源库页 | `/resources` | 查看历史生成资源 |
| 学习反馈页 | `/feedback` | 提交答题或实操结果，展示反馈决策 |
| 学情报告页 | `/report` | 展示能力雷达、学习路径、资源和反馈摘要 |

## 7. 指标

| 指标 | 目标 |
|------|------|
| 幻觉率 | `< 5%` |
| 知识点覆盖率 | `>= 90%` |
| 难度适配准确率 | `>= 85%` |
| 检索命中率 | `>= 90%` |
| 反馈后测试提升率 | 有明显提升 |
