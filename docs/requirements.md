# 需求分析文档

> 项目编号：XH-202630  
> 项目名称：领域知识个性化生成与多智能体协同决策系统  
> 文档版本：v1.0

## 1. 项目背景

学习者在掌握专业领域知识或工程技能时，经常遇到学习路径不清晰、资源难度不匹配、生成内容可信度不足、反馈无法驱动下一步学习等问题。单一模型直接生成内容难以同时兼顾个性化、专业准确性、可溯源和动态迭代。

## 2. 项目定位

系统通过学习者画像、领域知识库、多智能体协同、审核纠偏和学习反馈，生成可解释、可追踪、可迭代的个性化领域知识学习资源。

领域方向由用户输入和知识库决定，系统本身不绑定特定行业或技术方向。

## 3. 目标用户

| 用户类型 | 核心诉求 |
|----------|----------|
| 初学者 | 获得降维解释、基础讲义和入门练习 |
| 有基础学习者 | 获得实操任务、参数对比、针对性练习 |
| 进阶学习者 | 获得复杂任务、调优挑战、评测反馈 |
| 指导教师或评委 | 看到 Agent 协同、审核纠偏、量化指标和完整闭环 |

## 4. 功能需求

| 编号 | 功能模块 | 优先级 | 说明 |
|------|----------|--------|------|
| R01 | 学习者画像 | P0 | 管理背景、得分、强弱项和学习目标 |
| R02 | 能力诊断 | P0 | 输出能力等级、薄弱点和推荐方向 |
| R03 | 知识库检索 | P0 | 从当前领域知识库检索证据片段 |
| R04 | 多智能体协同 | P0 | 诊断、检索、规划、生成、审核、反馈决策闭环 |
| R05 | 个性化资源生成 | P0 | 生成讲义、实操指南、分阶测试题 |
| R06 | 审核纠偏与溯源 | P0 | 绑定来源证据，输出审核结论和风险指标 |
| R07 | 学习反馈与反馈决策 | P0 | 根据答题或实操结果调用反馈决策 Agent，更新画像和下一步策略 |
| R08 | 学情报告 | P0 | 聚合画像、资源、反馈和学习路径 |
| R09 | 历史查询 | P1 | 查询资源历史和反馈历史 |

## 5. 核心流程需求

```text
创建画像
→ 生成资源
→ 展示 Agent trace、资源、审核报告
→ 提交反馈
→ 反馈决策 Agent 更新画像与下一步建议
→ 查询学情报告和历史
→ 下一轮生成
```

## 6. 数据需求

| 数据对象 | 需求 |
|----------|------|
| 领域知识库 | 支持按配置切换不同领域知识库 |
| 学习者画像 | 保存学习背景、得分、强弱项和学习目标 |
| Agent trace | 保存或返回每个 Agent 的输入、输出、理由、证据 |
| 生成资源 | 保存资源正文、知识点、来源引用和文件路径 |
| 学习反馈 | 保存 resource_id、正确率、答题详情、反馈决策和下一轮建议 |
| 学情报告 | 聚合画像、资源历史、反馈历史和学习路径 |

## 7. 评测指标

| 指标 | 目标值 |
|------|--------|
| 幻觉率 | `< 5%` |
| 知识点覆盖率 | `>= 90%` |
| 难度适配准确率 | `>= 85%` |
| 检索命中率 | `>= 90%` |
| 反馈后测试提升率 | 有明显提升 |

## 8. 非目标说明

系统不以通用问答为最终目标，也不把某个领域硬编码为系统边界。所有检索、生成、审核和反馈能力都服务于可迁移的领域知识个性化学习闭环。
