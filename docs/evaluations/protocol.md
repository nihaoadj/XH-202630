# 真实测试执行说明

日常执行以[README](README.md)为准。

1. 在现有授权范围内，创建下一个 `E<N>/` 并记录测试目的和预期结果。并发创建冲突时重新取号，禁止覆盖。
2. 执行真实链路，记录实际入口、关键配置、命令及结果；缺少凭据/环境则如实记阻塞，不伪造成功。
3. 完成 `report.md`，必要结果文件放在同目录。报告必须有结论依据、未执行/未覆盖项；未知用量或费用标未知，不写0。无需额外JSON清单、索引或hash文件。
4. 失败、中断和复验分别留档；重新执行用新编号关联旧测试，不为凑通过擅自重跑。

只有明确要求模型对照评测时，才补充比较版本、相同输入与口径、指标/阈值、实际成本和限制。按需使用现有模板，不强制单次测试建立对照组、重复多轮或做统计推断。没有充分证据不宣称质量提升或生产就绪。
