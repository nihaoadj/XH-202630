# 真实测试记录

每次真实测试在本目录新建 `E<N>/`，编号按现有最大数字加一，无则从 `E1` 开始，不覆盖旧目录。复验使用新编号，报告注明前次编号；失败、中断和预检阻塞也保留。

唯一必需文件是 `report.md`：

```text
docs/evaluations/
  E1/
    report.md
  E2/
    report.md
```

报告简要记录：测试目的与日期、实际入口/配置/命令、run_id（如有）、预期与实际结果、结论和未覆盖项。可参考[简短模板](templates/report.md)，不重复填写清单或索引。

日志、JSON、截图、产物等仅保存支撑结论的必要文件，直接放在同一编号目录并在报告中链接。不要求额外子目录、test.json、索引或校验清单，不复制大批无关输出；大型或受限文件可引用原路径并说明限制。

真实测试沿用当前授权范围，不因本规范额外执行调用或扩大次数；不保存凭据或敏感信息。纯离线/mock测试继续原测试目录。真实结果默认本地留存，不自动提交或上传；已有历史目录和记录不搬迁、不删除。

需要补充解释时参阅[执行说明](protocol.md)和[结果说明](data-contract.md)，普通测试无需逐份阅读。仅在明确要求对照评测时按需使用原有对照模板。收尾在对应更新计划中链接本次报告。
