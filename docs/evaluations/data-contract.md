# 真实测试结果说明

唯一必需记录为当前 `E<N>/report.md`，内容精简到能判断本次测试是否达到目标：

- 测试目的、日期、实际入口/关键配置与命令；有业务run_id时注明。
- 预期与实际结果、成功/失败/阻塞结论及依据；没有真正执行必须明确写“未执行”。
- 未覆盖项，以及必要结果文件的链接；复验注明原测试编号。

日志、JSON、截图、产物仅在支撑结论时保留，直接放在同目录，格式沿用工具原输出，不新增强制schema。不得保存凭据或敏感信息；外部或受限资料写原路径及访问限制即可。每份报告必须按[调用用量与计费要求](README.md#调用用量与计费每份真实报告必填)说明用量、价格依据、估算/实际金额及完整性；未知不冒充0，无费用依据也必须明确写未知及原因。

既有实验数据及schema保持原样可读，不补写新格式、不改历史结论。原有experiment/metrics/comparison模板仅供明确要求的对照评测按需使用，不是每次测试的必需文件。
