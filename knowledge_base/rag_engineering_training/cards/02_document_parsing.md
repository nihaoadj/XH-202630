# 教学卡：文档解析与清洗

**能力节点**：文档解析｜**适用水平**：零基础｜**卡片 ID**：card_document_parsing

## 学习目标

掌握将 Markdown、TXT、PDF 等资料变为统一文本对象的原则，并保留可追溯的文档身份信息。

## 核心概念

解析的输出不只是正文。每篇文档至少应有 `knowledge_base_id`、`document_id`、标题、来源路径、版本、知识点和来源 URL。正文清洗应去除导航、重复页眉、无意义空白和无关广告，但不能删除定义、条件、示例或版本说明。

## 工程步骤

1. 为每份原始资料分配稳定 `document_id`。
2. 提取标题、正文和层级标题；保留原始相对路径。
3. 清除明显噪声，检查代码块和表格是否被破坏。
4. 计算内容哈希，便于判断资料是否更新。
5. 记录来源链接、访问日期和适用知识点。

## 常见错误

- 使用本机绝对路径作为来源，换电脑后无法溯源。
- 把网页菜单、版权栏和正文混在一个片段中。
- 文档更新后复用旧 ID 却没有版本或哈希记录。

## 小练习与评测点

将一份 Markdown 教程解析为文档对象，检查标题、来源路径和知识点是否完整。评测：字段完整率、解析失败率、更新可检测率。
