# 检索策略、Rerank 与 Prompt 组装

RAG 的答案质量不仅取决于是否使用向量检索，也取决于检索策略、重排序和 Prompt 组装方式。工程实践中常用相似度检索、关键词检索、混合检索和 Rerank 组合提升证据质量。

## 检索策略

相似度检索适合语义相关的问题，但对专有名词、参数名和代码符号可能不稳定。关键词检索适合精确匹配。混合检索结合向量召回和关键词召回，可以提升复杂文档问答的召回率。

## Rerank

Rerank 会对初始召回结果重新排序，优先保留与问题最相关的证据。常见做法是先召回较多候选片段，再用 Rerank 模型筛选前几个片段进入 Prompt。

## Prompt 组装

Prompt 应包含任务目标、学习者画像、检索证据、输出格式和引用要求。对于教学资源生成，还应加入学习者水平、薄弱知识点、学习路径和资源类型要求。

## 常见错误

- 只把检索片段堆进 Prompt，没有明确要求模型基于证据生成。
- Prompt 没有限制输出结构，导致前端和审核模块难以解析。
- Rerank 后不保留原始来源，影响引用溯源。
