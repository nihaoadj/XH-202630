# 引用溯源、幻觉控制与 RAG 评测

RAG 系统必须证明生成内容来自可靠证据。引用溯源、Claim 级审核和量化评测是降低幻觉、提升可信度的重要机制。

## 引用溯源

每个生成资源应绑定来源引用，包括文档 ID、标题、片段摘要和相似度。引用可以帮助学习者追踪知识来源，也方便审核 Agent 判断内容是否被证据支持。

## Claim 级审核

Claim 是生成内容中的关键事实、步骤或结论。Claim 级审核流程包括抽取 claim、检索证据、判断支持关系、不支持则退回重写、输出可信度评分。

审核指标包括 claim 总数、有证据支持数、无证据支持数、疑似幻觉数、幻觉率、审核通过率和审核修正次数。

## RAG 评测

RAG 评测应关注检索命中率、知识点覆盖率、答案或资源准确性、难度适配准确率和反馈后提升率。比赛展示中可以通过消融实验说明多智能体和审核纠偏的价值。

## 消融实验

1. 单 LLM 直接生成。
2. RAG + 单 LLM 生成。
3. RAG + 多 Agent 生成。
4. RAG + 多 Agent + 审核纠偏。

## 常见错误

- 只给整篇资源一个来源，无法证明每条关键结论都被支持。
- 只看生成流畅度，不计算幻觉率和覆盖率。
- 审核失败后没有纠错或重生成机制。

适合水平：进阶 RAG。
