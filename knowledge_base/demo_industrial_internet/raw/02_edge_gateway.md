# 边缘计算网关配置指南

## 硬件准备

边缘计算网关通常具备以下接口：
- RS485 / RS232：用于连接 Modbus RTU 设备。
- 以太网口：用于连接 OPC UA Server 或 MQTT Broker。
- 4G / 5G / Wi-Fi：用于远程上传数据。

## 配置步骤

### 步骤 1：连接设备

将 PLC 或传感器通过 RS485 连接至网关，确认接线正确，波特率、数据位、停止位与从机地址一致。

### 步骤 2：配置采集协议

在网关管理界面中，选择对应的采集协议：
- Modbus RTU：配置串口参数与寄存器映射。
- OPC UA：填写 OPC UA Server 的 endpoint URL 与命名空间。
- MQTT：配置 Broker 地址、端口、用户名、密码与发布主题。

### 步骤 3：设置边缘计算规则

在网关中配置数据清洗与预处理规则，例如：
- 数据阈值过滤：剔除异常跳变值。
- 数据聚合：按 1 分钟或 5 分钟进行均值、最大值、最小值统计。
- 告警规则：当温度超过阈值时触发本地告警并上报。

### 步骤 4：上传至云平台

配置云平台接入参数，包括设备三元组、TLS/SSL 证书、数据上送周期等。测试连通性后启动采集任务。

## 安全规范

- 工业网络应与办公网络物理隔离或采用 VLAN 隔离。
- 网关应启用防火墙，关闭不必要的端口。
- 数据传输应启用 TLS 加密。
